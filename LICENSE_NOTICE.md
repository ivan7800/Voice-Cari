# Aviso de uso responsable

Voice Cari es una herramienta para narración, accesibilidad, audiolibros, pruebas de voz y preparación de perfiles autorizados.

No debe utilizarse para:

- Suplantar a una persona.
- Clonar voces sin consentimiento explícito.
- Crear mensajes falsos atribuidos a terceros.
- Realizar fraudes, llamadas engañosas, acoso, extorsión o manipulación.
- Ocultar que un audio es sintético cuando pueda inducir a error.

El usuario es responsable de obtener permisos y cumplir las leyes aplicables sobre voz, imagen, datos personales, derechos de autor y privacidad.
